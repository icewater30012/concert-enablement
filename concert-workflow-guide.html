什麼是 Concert Workflows

  • 工作流程編排引擎:能夠執行複雜的交付與運維工作流程。
  • 流程網關 (Flow Gateway):為每個流程提供完全託管的 API 和 API 端點。
  • 自助服務入口網站:支援角色存取控制 (RBAC) 管理,可由使用者輸入資料來手動觸發流程°。
  • 豐富的支援:提供 250 多個廠商的 API
  • 整合現有資源:具備善用既有自動化資源(例如 Ansible)的能力。
  • 專為大型且複雜的流程設計,能輕鬆駕馭傳統腳本難以企及的超高規模自動化

Prerequisites - Install K3s (1/2)

Step 1: Download and Install K3s

下載並執行 K3s 安裝腳本:

curl -sfL https://get.k3s.io | sudo INSTALL_K3S_VERSION=v1.33.4+k3s1 sh -s - --write-kubeconfig-mode 644 --disable traefik

參數說明:

  • • INSTALL_K3S_VERSION=v1.33.4+k3s1 — 指定 K3s 版本
  • • --write-kubeconfig-mode 644 — 設定 kubeconfig 檔案權限
  • • --disable traefik — 停用預設的 Traefik ingress controller

K3s version compatibility: Use a supported K3s version between v1.29.2+k3s1 and v1.33.x.

安裝完成後,K3s 服務會自動啟動

Step 1 (續): 下載 K3s 元件和 Helm

設定環境變數並下載元件

# 設定版本變數
export K3S_RELEASE_VER=v1.33.4+k3s1
export HELM_VERSION=v3.20.0

# 建立前置目錄
mkdir -p prerequisites

# 下載 K3s binary
K3S_RELEASE_VER_ENCODE=$(echo $K3S_RELEASE_VER | sed 's/+/%2B/g')
curl -Lo ./prerequisites/k3s https://github.com/k3s-io/k3s/releases/download/${K3S_RELEASE_VER_ENCODE}/k3s
chmod a+x ./prerequisites/k3s

# 下載 K3s airgap images
K3S_RELEASE_VER_SHORT=$(echo $K3S_RELEASE_VER | sed 's/+.*//g')
curl -Lo ./prerequisites/k3s-airgap-images-amd64.tar.zst https://github.com/k3s-io/k3s/releases/download/${K3S_RELEASE_VER_SHORT}%2Bk3s1/k3s-airgap-images-amd64.tar.zst

# 下載 K3s install script
curl -Lo ./prerequisites/install.sh https://get.k3s.io/
chmod a+x ./prerequisites/install.sh

# 下載 Helm
helm_download_name=helm-${HELM_VERSION}-linux-amd64.tar.gz
curl -Lo ./prerequisites/${helm_download_name} https://get.helm.sh/${helm_download_name}

Step 3: 在離線 VM 上安裝 (2)

4. 驗證 images 目錄存在且包含所需封存檔

ls -lh images/*/

5. 使用 airgap 套件中的前置元件安裝 K3s

注意: 此步驟必須以 root 使用者執行

# 以 root 身份在離線 VM 上執行
export K3S_RELEASE_VER=v1.33.4+k3s1

# 建立 K3s images 目錄
sudo mkdir -p /var/lib/rancher/k3s/agent/images/

# 從前置元件複製 K3s airgap images
sudo /usr/bin/cp -f ./prerequisites/k3s-airgap-images-amd64.tar.zst /var/lib/rancher/k3s/agent/images/

# 複製 K3s binary 到系統路徑
sudo /usr/bin/cp -f ./prerequisites/k3s /usr/local/bin/
sudo chmod +x /usr/local/bin/k3s

# 安裝 K3s (停用 traefik)
INSTALL_K3S_SKIP_DOWNLOAD=true INSTALL_K3S_VERSION=${K3S_RELEASE_VER} ./prerequisites/install.sh --write-kubeconfig-mode 644 --disable traefik

Step 3: 在離線 VM 上安裝 (3)

注意: 此步驟必須以 root 使用者執行

Step 3: 在離線 VM 上安裝 (5)

etc/params.ini 範例
