什麼是 Concert Workflows

  • 工作流程編排引擎:能夠執行複雜的交付與運維工作流程。
  • 流程網關 (Flow Gateway):為每個流程提供完全託管的 API 和 API 端點。
  • 自助服務入口網站:支援角色存取控制 (RBAC) 管理,可由使用者輸入資料來手動觸發流程°。
  • 豐富的支援:提供 250 多個廠商的 API
  • 整合現有資源:具備善用既有自動化資源(例如 Ansible)的能力。
  • 專為大型且複雜的流程設計,能輕鬆駕馭傳統腳本難以企及的超高規模自動化

Prerequisites - Install K3s (1/2)

Step 1: Download and Install K3s

下載並執行 K3s 安裝腳本:

curl -sfL https://get.k3s.io | sudo INSTALL_K3S_VERSION=v1.33.4+k3s1 sh -s - --write-kubeconfig-mode 644 --disable traefik

參數說明:

  • • INSTALL_K3S_VERSION=v1.33.4+k3s1 — 指定 K3s 版本
  • • --write-kubeconfig-mode 644 — 設定 kubeconfig 檔案權限
  • • --disable traefik — 停用預設的 Traefik ingress controller

K3s version compatibility: Use a supported K3s version between v1.29.2+k3s1 and v1.33.x.

安裝完成後,K3s 服務會自動啟動

19

Prerequisites - Install K3s (2/2)

Step 2: Configure kubectl Access

設定 KUBECONFIG 環境變數:

echo "export KUBECONFIG=/etc/rancher/k3s/k3s.yaml" >> ~/.bashrc && source ~/.bashrc

Step 3: Verify K3s Installation

a) 檢查 K3s 版本

k3s --version

b) 檢查 K3s 服務狀態

c) 檢查節點狀態

kubectl get nodes

Concert & Concert Workflow
Air-gapped Installation

在無網路連線的環境中安全部署

22

Step 1: 下載安裝檔案

1. 下載 Concert 安裝包

wget https://github.com/IBM/concert-install/archive/refs/tags/v2.3.0.tar.gz tar -xzf v2.3.0.tar.gz cd concert-install-2.3.0

2. 準備映像清單

執行腳本生成映像清單:

./scripts/generate-image-list.sh > images.txt
23

Step 2: 下載容器映像

1. 登入 IBM Container Registry

export IBM_ENTITLEMENT_KEY= echo $IBM_ENTITLEMENT_KEY | podman login cp.icr.io -u cp --password-stdin

2. 下載所有映像

./scripts/download-images.sh images.txt ./concert-images

注意: 下載過程可能需要較長時間,取決於網路速度

24

Step 3: 傳輸到 Air-gapped 環境

1. 打包映像和安裝檔案

tar -czf concert-airgap-bundle.tar.gz concert-install-2.3.0/ concert-images/

2. 傳輸到目標環境

使用安全的方式傳輸檔案:

  • USB 儲存裝置
  • 安全檔案傳輸協議
  • 其他經批准的傳輸方式

3. 在目標環境解壓

tar -xzf concert-airgap-bundle.tar.gz
25

Step 4: 載入映像到本地 Registry

1. 設定本地 Registry 變數

export LOCAL_REGISTRY= export LOCAL_REGISTRY_USER= export LOCAL_REGISTRY_PASSWORD=

2. 登入本地 Registry

echo $LOCAL_REGISTRY_PASSWORD | podman login $LOCAL_REGISTRY -u $LOCAL_REGISTRY_USER --password-stdin

3. 上傳映像

./scripts/upload-images.sh concert-images/ $LOCAL_REGISTRY
26

Step 5: 執行安裝

1. 修改安裝配置

編輯 values.yaml 指向本地 Registry:

global: imageRegistry: imagePullSecrets: - local-registry-secret

2. 執行安裝腳本

./install.sh --airgap --registry $LOCAL_REGISTRY

提示: 安裝過程約需 15-30 分鐘

27

Step 6: 驗證安裝

1. 檢查 Pod 狀態

kubectl get pods -n concert

2. 檢查服務狀態

kubectl get svc -n concert

3. 訪問 Concert UI

取得訪問 URL:

echo "https://$(kubectl get svc concert-ui -n concert -o jsonpath='{.status.loadBalancer.ingress[0].ip}'):12443"
