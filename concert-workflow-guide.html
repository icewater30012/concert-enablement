什麼是 IBM Concert?

統一的 AI 驅動平台,用於應用程式資源管理與自動化

  • 整合多雲環境中的應用程式資源管理
  • 提供統一的可觀測性和控制平面
  • 透過 AI 驅動的洞察優化資源配置
  • 支援自動化工作流程和策略執行
04

Concert 核心功能

🎯 資源管理

統一管理跨多雲環境的應用程式資源,提供完整的資源清單和狀態追蹤

🔄 工作流程自動化

透過 Concert Workflows 建立和執行自動化任務,簡化日常運維操作

📊 可觀測性

整合監控、日誌和追蹤數據,提供全面的應用程式健康狀態視圖

🤖 AI 洞察

利用 AI 分析資源使用模式,提供優化建議和異常檢測

🔐 安全整合

與 Vault 等安全工具整合,實現憑證和密鑰的集中管理

📈 擴展性

支援自定義連接器和工作流程,適應不同的企業需求

05

Concert Workflows

Concert Workflows 是基於 Apache Airflow 的工作流程自動化引擎

  • 使用 Python 定義工作流程 (DAGs)
  • 支援複雜的任務依賴和排程
  • 提供豐富的內建 Operators 和 Hooks
  • 可視化工作流程執行狀態和歷史記錄
  • 與 Concert 平台深度整合
06

Concert 架構概覽

三層架構

  • 控制平面 — Concert 核心服務、API 和 UI
  • 工作流程層 — Concert Workflows (Airflow)
  • 數據層 — Concert Data Apps (分析和報表)

Verify IPv6 is enabled on you Concert Workflows if it is disabled

ip -6 addr show

(Optional) Run the following command to enable IPv6 on RHEL if it is disabled.

a) Edit sysctl configuration

ip -6 addr show

b) Add or uncomment these lines.

net.ipv6.conf.all.disable_ipv6 = 0 net.ipv6.conf.default.disable_ipv6 = 0

c) Apply Changes.

sudo sysctl -p

Prerequisites - Install K3s (1/2)

Step 1: Download and Install K3s

下載並執行 K3s 安裝腳本:

curl -sfL https://get.k3s.io | sudo INSTALL_K3S_VERSION=v1.33.4+k3s1 sh -s - --write-kubeconfig-mode 644 --disable traefik

參數說明:

  • • INSTALL_K3S_VERSION=v1.33.4+k3s1 — 指定 K3s 版本
  • • --write-kubeconfig-mode 644 — 設定 kubeconfig 檔案權限
  • • --disable traefik — 停用預設的 Traefik ingress controller

K3s version compatibility: Use a supported K3s version between v1.29.2+k3s1 and v1.33.x.

安裝完成後,K3s 服務會自動啟動

17

Prerequisites - Install K3s (2/2)

Step 2: Configure kubectl Access

設定 KUBECONFIG 環境變數:

echo "export KUBECONFIG=/etc/rancher/k3s/k3s.yaml" >> ~/.bashrc && source ~/.bashrc

Step 3: Verify K3s Installation

a) 檢查 K3s 版本

k3s --version

b) 檢查 K3s 服務狀態

sudo systemctl status k3s

c) 檢查節點狀態

kubectl get nodes

預期結果: 節點狀態應顯示為 Ready

Prerequisites - Install Helm

1. Download Helm installation script

curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 -o get-helm.sh

2. Make the script executable

chmod +x get-helm.sh

3. Install Helm

sudo ./get-helm.sh

4. Verify installation

helm version
離線環境部署

Concert & Concert Workflow
Air-gapped Installation

在無網路連線的環境中安全部署

20

Step 1: 下載安裝檔案

1. 下載 Concert 安裝包

wget https://github.com/IBM/concert-install/archive/refs/tags/v2.3.0.tar.gz tar -xzf v2.3.0.tar.gz cd concert-install-2.3.0

2. 準備映像清單

執行腳本生成映像清單:

./scripts/generate-image-list.sh > images.txt
21

Step 2: 下載容器映像

1. 登入 IBM Container Registry

export IBM_ENTITLEMENT_KEY= echo $IBM_ENTITLEMENT_KEY | podman login cp.icr.io -u cp --password-stdin

2. 下載所有映像

./scripts/download-images.sh images.txt ./concert-images

注意: 下載過程可能需要較長時間,取決於網路速度

22

Step 3: 傳輸到 Air-gapped 環境

1. 打包映像和安裝檔案

tar -czf concert-airgap-bundle.tar.gz concert-install-2.3.0/ concert-images/

2. 傳輸到目標環境

使用安全的方式傳輸檔案:

  • USB 儲存裝置
  • 安全檔案傳輸協議
  • 其他經批准的傳輸方式

3. 在目標環境解壓

tar -xzf concert-airgap-bundle.tar.gz
23

Step 4: 載入映像到本地 Registry

1. 設定本地 Registry 變數

export LOCAL_REGISTRY= export LOCAL_REGISTRY_USER= export LOCAL_REGISTRY_PASSWORD=

2. 登入本地 Registry

echo $LOCAL_REGISTRY_PASSWORD | podman login $LOCAL_REGISTRY -u $LOCAL_REGISTRY_USER --password-stdin

3. 上傳映像

./scripts/upload-images.sh concert-images/ $LOCAL_REGISTRY
24

Step 5: 執行安裝

1. 修改安裝配置

編輯 values.yaml 指向本地 Registry:

global: imageRegistry: imagePullSecrets: - local-registry-secret

2. 執行安裝腳本

./install.sh --airgap --registry $LOCAL_REGISTRY

提示: 安裝過程約需 15-30 分鐘

25

Step 6: 驗證安裝

1. 檢查 Pod 狀態

kubectl get pods -n concert

2. 檢查服務狀態

kubectl get svc -n concert

3. 訪問 Concert UI

取得訪問 URL:

echo "https://$(kubectl get svc concert-ui -n concert -o jsonpath='{.status.loadBalancer.ingress[0].ip}'):12443"
